ScoutVault turns a public listing into a short checklist. A scout signs the completed report, and the buyer reviews it before releasing the Solana escrow.

The [2:30 devnet walkthrough](https://scoutvault-checks.vercel.app/demo/) shows the full flow, including a finalized payout of two project test tokens. [Open ScoutVault](https://scoutvault-checks.vercel.app) · [View the public payout](https://explorer.solana.com/tx/3zSVqcCExnJiLqKwrtcEPzsxdhnuWQi3LKJLvwjnDB3PHXycJvsbXvBdo2qfsFBpwX2txAyxFN1RqRBA7iyw7ZXm?cluster=devnet).

The signed arm64 Android release supports the device camera, foreground location, speech, and Mobile Wallet Adapter. The video uses a labelled sample illustration and software demo wallets. Physical Seeker testing remains open. [Validation](https://github.com/NSEVEjk0/scoutvault/blob/main/docs/validation.md).
