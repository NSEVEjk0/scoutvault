ScoutVault reads a public listing, turns it into a short checklist, holds a small token bounty in Solana escrow, and lets the buyer review the scout's signed report before paying.

Open [ScoutVault](https://scoutvault-checks.vercel.app) or watch the [2:30 captioned walkthrough](https://scoutvault-checks.vercel.app/demo/). The recording includes an actual payout from the compiled Anchor program on a separate local validator, shown in Solana Explorer on that custom network. That local service has been retired after testing. TEST USDC has no cash value. The sample illustration does not claim a site visit.

The Android APK supports the native camera, foreground location, device speech, and Mobile Wallet Adapter. It is signed with the release certificate published in the website's Digital Asset Links. It targets arm64 Android devices. A physical Seeker test has not been performed.

Public devnet escrow activation is waiting for free test SOL. Buyer approval controls payout. A wallet signature binds report bytes to a wallet and bounty. Seed Vault can protect wallet keys, but does not attest a camera, GPS reading, physical presence, or student identity.

See the [validation record](https://github.com/NSEVEjk0/scoutvault/blob/main/docs/validation.md) for actual tests and limits. This development prototype has not received a security audit.
